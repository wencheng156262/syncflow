# SyncFlow Week 1 设计包

这里是 SyncFlow 的规范设计资料。根目录的 3 个 DOCX 是需求讨论阶段的原始记录；本目录中的 Markdown 是经过整理、可直接用于开发和 Review 的版本。

- `01-product-requirements.md`：范围、角色、目标、模块和核心流程
- `02-api-design.md`：REST 接口、参数、响应、状态码和错误码
- `03-database-design.md`：表结构、字段、约束和索引
- `04-state-machine.md`：任务状态和状态转换规则
- `05-page-design.md`：页面、路由和交互状态
- `06-exception-and-test-plan.md`：异常场景与测试计划
- `07-system-boundary.md`：系统边界图和核心流程图
