# SyncFlow 异常场景与测试计划

## 异常场景

| 场景 | 预期行为 |
| --- | --- |
| 请求缺少文件 | 返回 400 `INVALID_REQUEST` |
| 文件扩展名不是 `.csv` | 返回 400 `INVALID_FILE_EXTENSION` |
| 文件超过配置上限 | 返回 400 `FILE_TOO_LARGE`，删除临时文件 |
| 文件名包含路径 | 只保留 basename，服务端生成存储文件名 |
| MySQL 不可用 | `/readyz` 返回 503，业务接口返回统一错误 |
| Redis 不可用 | 创建任务不留在 `PENDING`，标记失败并返回 503 |
| 任务 ID 不存在 | 返回 404 `JOB_NOT_FOUND` |
| 分页参数越界 | 返回 400 `INVALID_REQUEST` |
| Worker 重复消费 | 使用状态条件更新，避免覆盖已完成任务 |
| CSV 单行数据非法 | 保存错误行，继续处理其余行 |
| 服务重启 | 已入库任务可根据状态和队列策略恢复或重试 |

## 测试分层

### 后端单元测试

- 文件扩展名、大小、文件名净化和 SHA-256 计算。
- 统一错误响应格式和状态码映射。
- 状态机合法/非法转换。
- 分页参数和状态筛选校验。

### MySQL 集成测试

- 三张表迁移可重复执行。
- 任务、成功记录和错误记录的字段约束。
- `(job_id, external_id)` 去重约束。
- 任务列表分页、排序和状态筛选。

### API 集成测试

- 创建任务返回 201 和 `PENDING`。
- 查询详情返回完整字段但不返回内部路径。
- 任务不存在返回 404 统一错误。
- MySQL/Redis 不可用时返回稳定错误，不泄露堆栈。

### 前端交互测试

- 创建、列表、详情页面的加载、空数据和失败状态。
- 状态筛选和分页保持 URL 参数。
- API 错误消息可读，未知路由显示 404。

### 验收场景

1. `docker compose up --build -d` 启动五个服务。
2. `/healthz` 返回 200，`/readyz` 在依赖就绪后返回 200。
3. 上传合法 CSV，任务经历 `PENDING -> RUNNING -> SUCCESS`。
4. 上传非法扩展名或超大文件，返回指定错误码。
5. 查询任务列表、详情和不存在的任务。
6. 运行前端 lint/build，运行后端单元测试和 MySQL 集成测试。
